# 可写层白化条目的检查点恢复契约

维护实现允许把文件系统归档中的同一overlay白化条目合并到内核检查点恢复出的tmpfs。白化条目必须是权限为0、设备号精确为0:0的字符设备，现有inode必须仍是该文件系统自己的共享白化inode。恢复保留原inode和所有硬链接，不重新创建设备、不改变文件类型，也不通过删除Git锁文件来绕过恢复。

此路径只处理文件系统与内核检查点同时包含同一删除标记的情况。普通文件、其他字符设备、块设备、FIFO、权限变化以及设备号截断均不能借用这一分支。原检查点的归档、来源和清理所有权仍由沙箱守护进程维护，本修改不授权更换检查点或重复运行未知创建。

回归目标为`//pkg/sentry/fsimpl/tmpfs:tmpfs_test`，包含重复合并、硬链接及链接数保持，以及类型、设备、权限和设备号范围的拒绝对照。实际验收必须另行使用完整配套的六程序运行时归档，在严格预算内执行含Git增删文件的真实任务，确认源退役、新Runtime恢复、响应应用、原评分器和物理清理；单元检查和程序文件存在都不能替代这一闭环。
